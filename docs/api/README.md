# API documentation

- [`openapi.json`](openapi.json): snapshot of the OpenAPI 3.1 document generated by the backend. CI fails when it differs from the code. Regenerate after any API change:

  ```bash
  cd backend && uv run python -m app.cli export-openapi --output ../docs/api/openapi.json
  ```

  Each operation shows its access level as `x-access-level` (the wording of `05-api-specification.md` section 1.7).
- [`../05-api-specification.md`](../05-api-specification.md): the human-readable catalog, payloads, error codes and rules. It is the source of truth; the code and the snapshot must match it.
- Interactive documentation: run the development stack (`docker compose -f docker-compose.yml -f docker-compose.dev.yml up`) and open http://localhost:8000/api/docs. In production the live document `GET /api/v1/openapi.json` requires sign-in.
