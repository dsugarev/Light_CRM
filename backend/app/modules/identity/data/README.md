# Data files

`common-passwords.txt` — the 10,000 most common passwords, one per line, from
SecLists (`Passwords/Common-Credentials/10k-most-common.txt`,
https://github.com/danielmiessler/SecLists), MIT License, Copyright (c) 2018
Daniel Miessler. Used by the password policy (FR-AUTH-03) to reject common
passwords, compared case-insensitively.
